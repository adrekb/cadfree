How the physics works

Text-to-CAD already exists. The gap is: can this be made on your machines, and will it actually do the job? Cadfree answers that in rungs, and tells you which rung ran.

Rung 0 — first-order (always on)

Bounding-box cantilever, printed knockdowns, mass from volume × density × infill. Catches “50 lb on 8 g of PLA” in milliseconds. Not FEA.

Rung 1 — MATLAB / Octave (Agent mode)

If MATLAB or GNU Octave is installed, the agent can run .m scripts: beam theory, deflection, buckling, custom load cases, plots. Octave is accepted wherever MATLAB is asked for — same policy as Carrot’s academia pack.

Rung 2 — mesh FEA

The production path is CadQuery → STEP/STL → Gmsh tetrahedral mesh → CalculiX (ccx) linear static → von Mises. That is the open stack (PyCCX, FreeCAD FEM, CadQuery’s gmsh plugin). Cadfree probes for gmsh and ccx and will not pretend FEA ran if they are missing.

You can still edit the CAD

The studio is not chat-only. The feature tree is CadQuery operations — click a fillet in the tree or on the 3D solid (after Rebuild with CadQuery installed). CadQuery is not a SolidWorks history kernel; we wrap Workplane at runtime and stamp face pick-ids into the STL. That is not OCCT topological naming. PARAMS sliders still rebuild without rewriting topology. Monaco lets you edit the script yourself.

Survey before geometry

The agent must not guess load direction, fasteners, environment, safety factor, or which standard applies. It opens a form in the chat. Answer it; the turn stays paused (SSE keepalives) until you submit.

Standards search

ISO, ASTM, ASME, DIN, SAE, MIL-STD, NAS, IPC, and manufacturer datasheets are searched on the public web, ranked with standards bodies first. The agent cites the URL. If the document is a paid PDF, it says so and does not invent clause numbers. Optional Brave Search key is in Settings.

DeepSeek V4 Pro

DeepSeek is text-only — it cannot read a drawing or a photo of a part. Drawings need a vision-native model: OpenAI GPT-4.1 / GPT-4o, Anthropic Claude, Gemini 2.5, or an OpenRouter vision model. Attach the image in chat. Thinking levels still work on DeepSeek for text-only agent work.

Drawing loop — silhouette IoU, not GIFT training

GIFT (ICML 2026) is a training method. Cadfree steals the runtime idea: build the solid, rasterize orthographic silhouettes (+x/+y/+z), score IoU against an attached drawing, iterate PARAMS. PNG works without extra packages. JPEG needs Pillow. Missing decoder → one sentence, never a fake IoU.

@cad handles, URDF, DXF, build123d

Click a live fillet to copy @cad[face:N]. list_cad_refs also lists feature/part/instance/joint handles. URDF writes unique instances + joints in metres (bbox inertia; gear/spring become fixed with a note). DXF is the convex hull of the largest-area projection — a laser silhouette, not a shop drawing. A script that import build123d (and not cadquery) runs on the same OCP kernel; no pick-ids. Optional CAD-Coder is Settings → an HTTP endpoint, never a required GPU.

Large assemblies

Shop-scale, not a car: unique parts (up to 32 solids) tessellated once, then linear / grid / circular / mirror instances (cap 400). Nested parent_id multiplies children. Fasteners are BOM lines. STL download is the active unique part.

Import from other programs

Fusion, SolidWorks, FreeCAD, Onshape, Inventor, Blender: use Import CAD (or drop the file in chat). STEP is the right assembly export — Cadfree splits solids and keeps world coordinates in each mesh. STL / 3MF / OBJ / PLY are single bodies (or a zip of them). Native .sldprt / .f3d / .ipt are not readable; export STEP or STL from that program. STEP needs CadQuery (pip install cadquery). Imported parts have no PARAMS — edit them there, re-import here.

Linkages — does it move, and what does the pin see?

CadQuery (OCCT) builds solids. It will not tell you if a four-bar locks, if two gears mesh, or what force is in a pin. Cadfree adds joints on instances: revolute, prismatic, gear, plus spring / torsion as force elements (they do not constrain the pose). A ground–crank–coupler–rocker loop is a planar four-bar. A crank–rod–slider with one prismatic is a slider-crank. Play scrubs the drive. Check reports lock-up, convex-hull SAT clash, min transmission (≥40°), gear pitch, and — when you named a load or hung a coil — quasi-static pin forces, holding torque, Wahl shear, and solid height. 1-DOF ωn = √(k/m) is the suspension/latch oscillator, not Adams and not mẍ of the assembly. Coils are catalog rows like motors. Not SolidWorks Motion, not contact dynamics, not a PE stamp.

Generative design — packaged SIMP, not Fusion

Autodesk Generative Design is a cloud product (level-set / lattice / T-splines). Cadfree’s analogue is the open research method behind that look: SIMP (Sigmund’s 99-line MATLAB code, Liu & Tovar 3-D). After Rebuild, Generate voxelizes the SI mesh copy, runs a short optimality-criteria loop, and drops 1–3 organic STL candidates as imported parts next to the source. Mill shops get a 2.5-D extrusion filter; FDM/SLA get a crude overhang squeeze. Scipy is required (pip install 'cadfree[physics]'). Compliance is the voxel FEM model, not CalculiX. CadQuery is not rewritten — you still edit the parametric solid yourself.

Physics — CadQuery writes the solid, solvers get a copy

The SI snapshot (metres, N, Pa) is what every solver sees. Formula-book LaTeX is always on. Gmsh + CalculiX is linear static C3D10; missing binaries are named, never faked.

Impellers — meanline, CENTRIF, OpenRadioss, not CFD

A centrifugal impeller is not a bracket with rpm. draft_impeller writes a parametric CadQuery solid (backplate, hub, blades whose meanline follows β from the tangential). pack=turbo runs Euler head with Wiesner slip, SI specific speed, NPSHa, and thin-ring hoop — then CalculiX *DLOAD, CENTRIF (magnitude ω² about +Z, hub fixture). OpenRadioss is an explicit /LOAD/CENTRI burst/containment rung if the starter/engine are on PATH; it will not invent a burst factor. OpenFOAM MRF is a rotating-frame template on the full 360° STL, not TurboGrid and not a pump curve. The PARAMS search for head/hoop is meanline-only — it does not scale the mesh the way a bracket thickness hunt does. NPSHr and hydraulic efficiency are never invented; survey them or leave them blank.

COTS — buy electronics, design around them

Same loop as a 50 lb bracket: survey what you don't know, check_feasibility, refuse the impossible spec, then design. Whoop vs 5-inch lives in the workshop catalog (cots_classes), not a special agent. Class cost floors plus leftover thrust vs drag — not a propeller map. Then search a street-typical parts catalog plus vendor pages, and hole a printable airframe around those envelopes. Motors, FC, ESC, and batteries stay purchased BOM lines. template=drone is only a shortcut for the form.

MCP — stateless 2026-07-28

The same skills are on POST /mcp as Streamable HTTP. No initialize, no Mcp-Session-Id. Each request carries protocol version in headers and _meta. Pass project_id on every tools/call — that is the handle, not a transport session. Surveys come back as input_required (MRTR) instead of a held-open stream.
